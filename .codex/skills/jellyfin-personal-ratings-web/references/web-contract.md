# Web 交互契约

## 详情页

至少应展示：

- 当前评分状态
- 5 星样式评分组件
- 清除评分按钮
- 待删除切换按钮
- 管理员可见删除按钮

要求：

- 支持读取当前用户当前条目的已有评分
- 支持重复修改评分
- 保存后即时刷新 UI

## 管理页

页面名称：**我的评分库**

至少包含：

- 顶部筛选区
- 内容列表区
- 批量操作区
- 分页区

建议视图：

- 全部已评分
- 5 分 / 4 分 / 3 分 / 2 分 / 1 分
- 未评分
- 待删除
- 最近评分
- 已播放未评分

列表项建议字段：

- 缩略图
- 标题
- 年份
- 媒体类型
- 当前评分
- 是否已播放
- 是否待删除
- 最近评分时间

## 筛选条件

- 分数
- 是否已播放
- 是否待删除
- 所属媒体库
- 媒体类型
- 年份
- 最近添加时间
- 最近评分时间
- 名称关键字

## 批量操作

- 批量改分
- 批量清分
- 批量标记待删除
- 批量取消待删除
- 批量物理删除

其中物理删除只对管理员开放。

## 前端范围约束

1. 第一版只保证 Web 端
2. 先有后端契约，再做前端交互
3. 不要把 Favorite 当主流程依赖
4. 不要用重型前端方案替代最小静态资源
