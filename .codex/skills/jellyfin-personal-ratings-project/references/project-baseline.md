# 项目基线

## 项目目标

- 为 Jellyfin 10.10.7 开发 `Jellyfin.PersonalRatings`
- 面向个人素材库管理场景
- 用私有评分替代 Favorite 的粗粒度收藏
- 重点支持 Jellyfin Web 端

## 核心能力

1. 对视频条目打 `1~5` 分
2. 清除评分后回到 `0=未评分`
3. 按评分、待删除、已播放等条件管理素材
4. 分页查询和批量操作
5. 管理员物理删除与审计日志

## 用户与权限

- 所有评分按 Jellyfin 用户维度隔离
- 普通用户可以：
  - 给自己的条目评分
  - 清分
  - 查看自己的评分列表
  - 标记或取消待删除
- 管理员额外可以：
  - 执行物理删除
  - 查看或使用删除审计能力

## 关键业务规则

1. `0` 表示未评分，`1~5` 为有效评分
2. 每个 `UserId + ItemId` 只能有一条有效评分记录
3. 待删除只是管理标签，不代表实际删除
4. 物理删除必须二次确认、必须审计
5. 列表接口必须分页，不允许一次性返回所有数据

## 明确不做

1. 第一版不做 Android / iOS / TV 原生客户端 UI
2. 不做第三方评分站联动
3. 不做推荐算法
4. 不做公开评分或社区评分
5. 不以 Jellyfin 原生 Favorite 作为主数据源

## 可预留但不强依赖

- 配置项可支持“评分达到阈值后同步 Favorite”
- 默认不把 Favorite 当成主流程必需品
