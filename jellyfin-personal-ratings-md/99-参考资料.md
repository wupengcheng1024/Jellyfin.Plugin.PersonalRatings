# 参考资料

以下资料用于帮助 Codex 或开发者理解方向，避免偏离官方或社区常见做法。

## 1. Jellyfin 官方插件模板

用途：

- 了解 Jellyfin 插件项目的基本结构
- 了解 `PluginConfiguration : BasePluginConfiguration`
- 了解 `Plugin : BasePlugin<PluginConfiguration>`
- 了解 `net8.0` 目标框架方向

参考：

- https://github.com/jellyfin/jellyfin-plugin-template

## 2. Jellyfin 官方插件安装文档

用途：

- 了解手动安装插件的基本方式
- 了解插件目录的概念
- 了解重启 Jellyfin 后加载插件的流程

参考：

- https://jellyfin.org/docs/general/server/plugins/

## 3. JavaScript Injector（社区插件）

用途：

- 用于快速验证 Web UI 注入类原型
- 可作为详情页评分 UI 的快速原型参考
- 仅适合原型验证，不建议长期强依赖

参考：

- https://github.com/n00bcodr/Jellyfin-JavaScript-Injector

## 4. Plugin Pages（社区插件）

用途：

- 提供插件用户页面能力的实现思路
- 可参考其页面集成方式

参考：

- https://github.com/IAmParadox27/jellyfin-plugin-pages

## 5. 手动安装与部署注意点

如果需要手动安装插件，一般做法是：

1. 编译插件
2. 将输出复制到 Jellyfin 插件目录下的一个子目录
3. 重启 Jellyfin
4. 检查插件是否被识别

## 6. 给 Codex 的提醒

这些资料是参考方向，不代表当前项目必须强依赖这些第三方插件。
当前项目的正式实现目标仍然应以：

- 后端自定义插件
- 自带最小前端资源
- Jellyfin 10.10.7 适配

为主。
