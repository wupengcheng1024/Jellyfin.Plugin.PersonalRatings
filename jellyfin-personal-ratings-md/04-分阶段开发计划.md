# 分阶段开发计划

## 阶段 0：项目初始化

目标：
把一个最小插件工程搭起来，并能被 Jellyfin 识别。

交付物：

- `csproj`
- `Plugin.cs`
- `PluginConfiguration.cs`
- 基础目录结构
- README 草稿

完成标准：

- 能编译
- Jellyfin 能识别插件

## 阶段 1：数据层与基础 API

目标：
完成评分数据持久化与最核心接口。

任务：

1. SQLite 初始化
2. 建表脚本
3. Repository 骨架
4. RatingService 骨架
5. 评分相关 API

交付物：

- `DatabaseInitializer`
- `SqliteConnectionFactory`
- `RatingRepository`
- `RatingService`
- `RatingController`

完成标准：

- 可对单个条目打分
- 可查询当前评分
- 可清除评分

## 阶段 2：评分列表查询

目标：
提供管理页使用的分页查询接口。

任务：

1. 设计分页请求模型
2. 实现条件查询 SQL
3. 支持排序与分页
4. 返回管理页所需字段

交付物：

- `RatingQueryRequest`
- `RatingQueryResponse`
- `RatingsQueryController`

完成标准：

- 可按评分分页查询
- 可按待删除、关键词等条件筛选

## 阶段 3：批量操作

目标：
让管理页具备批量管理价值。

任务：

1. 批量改分
2. 批量清分
3. 批量设为待删除
4. 批量取消待删除

交付物：

- `RatingBatchController`
- 批量服务方法

完成标准：

- 批量接口可调用
- 有基本参数校验

## 阶段 4：详情页 Web 交互

目标：
用户能在详情页直接打分。

任务：

1. 编写 `details-rating.js`
2. 渲染评分组件
3. 加载已有评分
4. 点击提交评分
5. 支持清除评分

完成标准：

- 在详情页看得到评分 UI
- 打分成功后立即生效

## 阶段 5：管理页 Web 交互

目标：
做出一个可用的评分管理页。

任务：

1. `manage-page.html`
2. `manage-page.js`
3. `manage-page.css`
4. 筛选区
5. 列表区
6. 多选与批量操作按钮

完成标准：

- 能展示分页数据
- 能执行批量改分/清分/待删除

## 阶段 6：物理删除与审计

目标：
完成危险操作闭环。

任务：

1. 管理员权限校验
2. 物理删除服务
3. 删除审计日志
4. 删除结果反馈

完成标准：

- 普通用户无法调用物理删除
- 管理员可以批量删除
- 删除行为有日志

## 阶段 7：收尾与文档

目标：
让项目可交付、可继续维护。

任务：

1. 完善 README
2. 增加 TODO 列表
3. 补充部署说明
4. 补充后续扩展点
