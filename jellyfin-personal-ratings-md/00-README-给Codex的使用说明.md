# Jellyfin Personal Ratings - 给 Codex 的使用说明

这是一组专门为 Codex 准备的 Markdown 文档，用于在上下文有限、可能中途丢失记忆的情况下，分批稳定推进一个 Jellyfin 自定义插件项目。

## 项目目标

为 Jellyfin 10.10.7 开发一个“个人评分 + 分级收藏 + 批量管理”插件，主要服务于 Web 端。

核心诉求：

1. 对视频进行 **1~5 分**的私有评分。
2. 用评分替代 Jellyfin 原生 Favorite 的粗粒度收藏能力。
3. 按分数分类查看视频。
4. 按筛选结果进行批量操作。
5. 支持待删除标记与管理员物理删除。

## 使用原则

1. **优先保证能编译通过。**
2. **优先保证后端稳定。**
3. **不要一开始追求所有前端细节。**
4. **不要让 Codex 猜测不存在的 Jellyfin API。**
5. **每一轮都要求输出变更摘要。**

## 给 Codex 的统一要求

你可以在每轮提示词前附上下面这段总要求：

```text
请严格遵守以下要求：
1. 先保证项目可编译，再逐步补全功能。
2. 不要伪造未知的 Jellyfin API；如不确定，请标记 TODO 或用适配层隔离。
3. 局部变量使用显式类型，不使用 var。
4. 优先最小差异实现，不要大面积重写。
5. 所有新建代码文件默认 UTF-8。
6. 输出时请说明：哪些代码已完成、哪些地方仍是 TODO、哪些 Jellyfin API 需要二次核对。
```

## 交付标准

当 Codex 完成第一阶段后，至少应满足：

- 项目可编译。
- 插件能被 Jellyfin 识别。
- SQLite 数据库可初始化。
- 可以对单个 `ItemId` 完成打分、清分、查询。
- 提供基础分页查询接口。
